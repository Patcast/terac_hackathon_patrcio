# Tamoa

Fractional CFO as a service. Built for the Terac hackathon.

## Overview

Small businesses can't afford a full-time CFO and don't get one from their bookkeeper.
**Tamoa** is the product; **Tammy** is the agent on iMessage. She reads a company's real
accounting data in Odoo (read-only), answers in plain language, and escalates judgment
calls to real finance experts.
