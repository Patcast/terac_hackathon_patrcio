# Tamoa

Fractional CFO as a service. Built for the Terac hackathon.

## Overview

Small businesses can't afford a full-time CFO and don't get one from their bookkeeper.
Tamoa is an agent that reads a company's real accounting data in Odoo (read-only),
answers financial questions in plain language over iMessage, and escalates the calls that
need human judgment to real finance experts.
