**Linq**

Linq gives your agent a **_real phone number_** on **_iMessage_**. Linq supports  iMessage, RCS and
SMS from one API, plus rich media, Find My location, effects, reactions, typing indicators, read
receipts, and realtime webhooks on every event. The part most people don't know about: iMessage
Apps, an interactive card that renders inside iMessage. Use it as a visual or interactive component:
a game board redraws after a move, an order flips from "Reserved" to "Confirmed" in the familiar
blue bubble. And with Payments support through our AgentCard, Stripe, and Natural integrations, your
agent can now buy things for you.

**To get started, follow these instructions:**

1. Go to [](https://linqapp.com/cli)https://linqapp.com/hackathon to learn more about Linq.
2. Once you are ready, visit the Sandbox Signup page and select **“Hackathon”** in the “How did you
   hear about us?” dropdown.
3. Make sure to apply our best practices instructions
4. Let us know of any questions or if you run into any issues!

Idea starter: Build an agent and flow that takes advantage of iMessage Apps. Ideally you build
something unique to a vertical, not a generic claude-wrapper bot. Additionally, the best projects
will treat messaging primitives as UI: a 👍 tapback is a vote, a typing indicator is a loading
state, a group thread is your multiplayer lobby.

In the past, we’ve seen teams: build a food ordering bot using the Doordash CLI, trade on Kalshi via
Claude, and book a reservation via Resy.
